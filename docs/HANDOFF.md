## Что это
Аддон Home Assistant «Тренировочный центр» (репозиторий `spectr-on/training-center`, код в `training_center/app/`). Владелец — Сергей, Пермь, Garmin Instinct 3, HA OS на ноутбуке. Заменяет скрипт на игровом ПК (`D:\Programs\Claude\Тренировки\GarminConnect\Выгрузка данных\garmin_export.py`, пока не выключаем). Спецификация v0.1: https://claude.ai/code/artifact/fbad515d-5662-4118-965c-5717a5f192df (читать только нужные разделы; Docs-коннектор `read` по узлу `44ce921e-dc45`). Разделы 4/5/8/15 сверены с проверенными фактами и с кодом 13.10 (см. пункты 5 и 7 ниже). Спецификация не описывает интерфейс 0.10–0.11 (вкладки, таблицы, поля бега) — см. пункт 10.

## Что готово и проверено Сергеем на его HA
- Синхронизация с Garmin Connect (кнопка, каждые 3 ч круглосуточно, при старте; утром 05–12 повтор каждые 15 мин, пока нет сна и утреннего Readiness). Первый запуск качает 30 дней, обычные — 3 дня. Библиотека `garminconnect==0.3.17`, токены в `/config/garmin/garmin_tokens.json`.
- Светофор (зелёный/жёлтый/красный/серый) по утренним значениям; правила в `traffic.py`.
- Недельный план (пн–вс), слоты из программы, дни меняются в интерфейсе.
- Программа в YAML с версиями и откатом; черновик из последних тренировок Garmin «Full Body A/B»; бег без дня.
- Автоматическая прибавка веса (`progress.py`, правило с v0.12.0): все подходы упражнения на верху диапазона и на плановый вес → вес растёт **во всех подходах сразу** на `step_kg` упражнения, повторы возвращаются к низу диапазона (диапазон `reps` в программе не меняется). Шаг — поле `step_kg` упражнения в YAML; по умолчанию штанга 2,5 кг (общий вес), гантели 1,25 кг (на гантель); у других снарядов шага по умолчанию нет (без `step_kg` автоповышения нет). Прежний общий `progression.step_kg` не читается и не требуется (в старых программах игнорируется). Создаёт версию «авто». Правило «волна с последнего подхода» (+5/+2,5) убрано, `progress.next_bump` удалён.
- Отправка тренировки в Garmin (`garmin_workout.py`): одна группа на упражнение, вес группы = максимум по подходам, повторы = верх диапазона; вес в кг как есть. Автообновление после прибавки. Проверено: часы показывают веса и повторы верно. Автоматическая отправка на часы (`push_to_device`, переключатель в разделе «Программа») проверена Сергеем и работает; по умолчанию выключена.

Проверено: отчёт появился в GitHub.

## Проверенные факты про Garmin (подробнее `docs/garmin-findings.md`)
- Вес в шаге тренировки: `weightValue` в кг, `weightUnit` kilogram factor 1000. В подходах активности `weight_raw` в граммах (делитель 1000).
- Структура: RepeatGroupDTO (iterations) → упражнение (reps) + отдых (time). Суперсет — одна группа из 4 шагов.
- Журнал образа жизни: `get_lifestyle_logging_data(дата)`, отмечено при `logStatus == "YES"` (`"NO"` — явное «нет», ключа нет — не отмечено). Пункты на 25.10.2026: «Кальян» (CUSTOM, `measurementType QUANTITY`, число в `details[0].amount`, id 868349), «Alcohol» (LIFESTYLE, QUANTITY, `details[]` с `subTypeName` BEER/WINE/SPIRIT/OTHER и `amount`), «Healthy Meals» (NONE), «Болезнь» (CUSTOM, NONE). `completionStats` в ответе даёт число отслеживаемых пунктов по дням (с 22.10 их 4, раньше 3). `calendarDate` — день отметки; влияние на сон смотреть на следующее утро.
- **Как быстро проверить данные Garmin API из терминала HA** (SSH-терминал; `garminconnect 0.3.17` там уже установлена): `cd /root`, скачать скрипт `curl -sLO https://raw.githubusercontent.com/spectr-on/training-center/main/tools/check_lifestyle.py`, запустить на КОПИИ живого токена аддона: `rm -rf /root/gt && cp -r /addon_configs/6b002eec_training_center/garmin /root/gt && python3 check_lifestyle.py /root/gt --days 3`. Токен в `/homeassistant/garmin_token` устарел (вход падает с «Failed to retrieve social profile»); живой токен — только у аддона (`/config/garmin` внутри аддона). Полный ответ скрипт пишет в `/root/lifestyle_dump.json` (порядок дней: новые первыми; в терминале «первый день» = сегодня, в файле последний блок = самая старая дата, расхождения нет). Колесо мыши в терминале листает историю команд, не экран: выводить компактно (`python3 - <<'PY'` с разбором JSON) или скопировать файл в `/homeassistant/` и забрать по сети (`\\HOMEASSISTANT\config\`). Не гонять запросы подряд при ошибках входа, чтобы Garmin не ограничил вход.
- Время в БД — местное (`timeutil`, по умолчанию Asia/Yekaterinburg).

## Как работать
- Клонировать `spectr-on/training-center` (и `spectr-on/training-reports` при необходимости), версия в `training_center/config.yaml`.
- Тесты: `tests/test_*.py`, без pytest (известный сбой, не связан с кодом: `test_body.test_page_renders_and_sections` зависит от текущей даты — пробежка 13.10 старше окна «10 дней», поэтому «Как ощущался бег?» не находится); запуск — вызвать все функции `test_*` каждого модуля (см. цикл в конце этого файла). Последний прогон: ALL OK.
- Миграции БД нумерованные в `db.py` (сейчас 7), перед миграцией делается копия файла.
- Коммиты: на русском, с трейлерами Co-Authored-By и Claude-Session из системного напоминания.
- Любое изменение — версия в `config.yaml` +1, коммит, push, затем Сергей обновляет аддон в HA и проверяет. Хук `stop-git-check` напоминает о непушенных коммитах; интерфейсные правки пушатся после согласования макета и скриншотов.
- Не класть токены в репозиторий; `.gitignore` содержит `*.json`.
