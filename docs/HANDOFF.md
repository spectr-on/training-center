## Что готово и проверено Сергеем на его HA
- Синхронизация с Garmin Connect (кнопка, каждые 3 ч, при старте; утром 05–12 повтор каждые 15 мин, пока нет сна и утреннего Readiness). Библиотека `garminconnect==0.3.17`, токены в `/config/garmin/garmin_tokens.json`.
- Светофор (зелёный/жёлтый/красный/серый) по утренним значениям; правила в `traffic.py`.
- Недельный план (пн–вс), слоты из программы, дни меняются в интерфейсе.
- Программа в YAML с версиями и откатом; черновик из последних тренировок Garmin «Full Body A/B»; бег без дня.
- Автоматическая прибавка веса (`progress.py`): все подходы на верх диапазона и на плановый вес → +5 кг штанга / +2,5 кг гантели последнему подходу из минимальных по весу. Создаёт версию «авто».
- Отправка тренировки в Garmin (`garmin_workout.py`): одна группа на упражнение, вес группы = максимум по подходам, повторы = верх диапазона; вес в кг как есть. Автообновление после прибавки. Проверено: часы показывают веса и повторы верно.
- Отчёт для ИИ (`report.py`, v0.7.0): Markdown по приложению B спецификации; отправка в `spectr-on/training-reports` (`latest.md` + `reports/ГГГГ-ММ-ДД.md`), токен в настройке аддона `github_token`; копирование текстом; автоотчёт после новой тренировки (переключатель). Проверено: отчёт появился в GitHub.

- Сенсоры и события HA через MQTT discovery (`ha_mqtt.py`, v0.8.0): `sensor.training_traffic_light`, `training_today_session`, `training_week_done`, `training_last_sync`, `binary_sensor.training_garmin_ok`, `event.training_workout_done` (+ событие шины `training_workout_done`). Брокер берётся у Supervisor (Mosquitto) или из настроек `mqtt_host/port/user/password`. Состояния с retain, обновление после синхронизации и каждые 5 минут. НЕ проверено на реальном HA — Сергей проверяет после обновления.

## Проверенные факты про Garmin (подробнее `docs/garmin-findings.md`)
- Вес в шаге тренировки: `weightValue` в кг, `weightUnit` kilogram factor 1000. В подходах активности `weight_raw` в граммах (делитель 1000).
- Структура: RepeatGroupDTO (iterations) → упражнение (reps) + отдых (time). Суперсет — одна группа из 4 шагов.
- Журнал образа жизни: `get_lifestyle_logging_data`, `logStatus == "YES"`, Алкоголь/Кальян/Болезнь.
- Время в БД — местное (`timeutil`, по умолчанию Asia/Yekaterinburg).

## Как работать
- Клонировать `spectr-on/training-center` (и `spectr-on/training-reports` при необходимости), версия в `training_center/config.yaml`.
- Тесты: `tests/test_*.py`, без pytest; запуск — вызвать все функции `test_*` каждого модуля (см. цикл в конце этого файла). Последний прогон: ALL OK.
- Миграции БД нумерованные в `db.py` (сейчас 6), перед миграцией делается копия файла.
- Коммиты: на русском, с трейлерами Co-Authored-By и Claude-Session из системного напоминания.
- Любое изменение — версия в `config.yaml` +1, коммит, push, затем Сергей обновляет аддон в HA и проверяет.
- Не класть токены в репозиторий; `.gitignore` содержит `*.json`.
