Спецификация v0.1: https://claude.ai/code/artifact/fbad515d-5662-4118-965c-5717a5f192df (читать только нужные разделы; Docs-коннектор `read` по узлу `44ce921e-dc45`).

Для сущностей используется `default_entity_id` (не `object_id`).

## Проверенные факты про Garmin (подробнее `docs/garmin-findings.md`)
- Вес в шаге тренировки: `weightValue` в кг, `weightUnit` kilogram factor 1000. В подходах активности `weight_raw` в граммах (делитель 1000).
- Структура: RepeatGroupDTO (iterations) → упражнение (reps) + отдых (time). Суперсет — одна группа из 4 шагов.
- Журнал образа жизни: `get_lifestyle_logging_data`, `logStatus == "YES"`, Алкоголь/Кальян/Болезнь.
- Время в БД — местное (`timeutil`, по умолчанию Asia/Yekaterinburg).

## Как работать
- Клонировать `spectr-on/training-center` (и `spectr-on/training-reports` при необходимости), версия в `training_center/config.yaml`.
- Тесты: `tests/test_*.py`, без pytest; запуск — вызвать все функции `test_*` каждого модуля (см. цикл в конце этого файла). Последний прогон: ALL OK.
- Миграции БД нумерованные в `db.py` (сейчас 7), перед миграцией делается копия файла.
- Коммиты: на русском, с трейлерами Co-Authored-By и Claude-Session из системного напоминания.
- Любое изменение — версия в `config.yaml` +1, коммит, push, затем Сергей обновляет аддон в HA и проверяет.
- Не класть токены в репозиторий; `.gitignore` содержит `*.json`.
